# 🌱 Sprout

یک اپلیکیشن to-do list که به‌جای چک‌لیست‌های خشک و بی‌روح، یه گیاه مجازی داره که با انجام کارهات رشد می‌کنه — و با رها کردنشون پژمرده می‌شه.

ایده‌ی اصلی ساده است: انجام کارها فقط یه تیک روی یه لیست نیست، یه اثر واقعی روی چیزی داره که ازش مراقبت می‌کنی.

---

## ✨ ویژگی‌ها

- **گیاه زنده که رشد می‌کنه** — از دانه تا شکوفایی، در ۴ مرحله‌ی بصری متفاوت
- **کارهای «حیاتی»** — هر روز تا ۳ تا کار رو می‌تونی به‌عنوان حیاتی علامت بزنی. رها کردنشون تا آخر روز، گیاه رو پژمرده می‌کنه
- **پیامد واقعی، نه فقط امتیاز** — سلامت گیاه مستقیماً بر اساس رفتار روزانه‌ت تغییر می‌کنه
- **استریک روزانه** — اگه همه‌ی کارهای حیاتی‌ت رو تموم کنی، استریکت حفظ می‌شه
- **ذخیره‌سازی خودکار** — همه‌چیز بین جلسه‌ها و روزها باقی می‌مونه
- **رابط کاربری فارسی و راست‌به‌چپ** — طراحی‌شده با فونت‌های Fraunces و Vazirmatn

## 🚀 نحوه‌ی استفاده

این پروژه یه فایل تک‌صفحه‌ای HTML/CSS/JavaScript هست — بدون نیاز به نصب یا بیلد.

1. مخزن رو کلون کن یا فایل `sprout.html` رو دانلود کن
2. فایل رو مستقیماً توی مرورگر باز کن، یا با یه سرور ساده سرو کن:

```bash
git clone https://github.com/<username>/sprout.git
cd sprout
open sprout.html   # یا: python3 -m http.server
```

هیچ وابستگی (dependency) یا فرآیند بیلدی لازم نیست.

## 🧠 منطق برنامه

| بخش | توضیح |
|---|---|
| **سلامت گیاه** | عددی بین ۰ تا ۱۰۰، بر اساس تکمیل کارها بالا و پایین می‌ره |
| **مراحل رشد** | دانه (۰–۲۰) → جوانه (۲۱–۴۵) → در حال رشد (۴۶–۷۰) → شکوفا (۷۱–۱۰۰) |
| **کار حیاتی** | حداکثر ۳ کار در روز؛ تکمیل‌شده = رشد بیشتر، رهاشده = افت سلامت و شکست استریک |
| **کار عادی** | تکمیلش رشد کوچیک‌تری به همراه داره |

## 🛠️ تکنولوژی
